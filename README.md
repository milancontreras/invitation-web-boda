# Invitación de boda · Pau & Milan

Página web de la invitación (`index.html`), publicada con GitHub Pages.

- Los datos de la boda se cambian en el bloque `CONFIG` al inicio de `index.html`.
- Cada invitado tiene su link personal: `…/?i=CÓDIGO`. Los códigos, los pases y las confirmaciones se manejan en la hoja de Google *InvitacionWeb*.
- Las confirmaciones llegan a la hoja a través de Apps Script (`API_URL` en `CONFIG`).
